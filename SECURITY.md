# Security

Colorroom FABLE runs entirely on your computer and never connects to the internet.

## Reporting a problem

If you find a security problem, for example an image file that crashes the app or makes it
behave in a way it should not, please report it privately:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.

Please do not open a public issue for a security problem. Ordinary bugs and suggestions are
welcome in Issues.

## Supported versions

Only the latest release receives fixes.
